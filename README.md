# TUM 3rd Semester Compulsory Module Tutorials

- Since the official university portal (TUMonline) frequently crashes or slows down, I often had to painstakingly search for tutorial times one by one. 
To streamline this process and make things easier—both for myself and my fellow students—I developed this Flask web application.

- When I am on campus with a free window between classes, I can 
now instantly filter by modules and start times to see right away which tutorials are taking place during that time slot.
